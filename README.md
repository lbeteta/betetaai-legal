# BetetaAI legal pages (Twilio A2P 10DLC)

Contains static pages for BetetaAI's internal developer-only SMS testing campaign.

## Before publication

1. Replace `[YOUR CONTACT EMAIL — REPLACE BEFORE PUBLISHING]` in `index.html`, `privacy.html`, and `terms.html` with a working business contact email.
2. Confirm all statements reflect actual operations, including opt-in, message controls, vendor practices, STOP/HELP handling, and data retention. Do **not** claim consent or allowlist that does not exist.
3. Upload the four website files (`index.html`, `privacy.html`, `terms.html`, `style.css`) to a **public** `lbeteta/betetaai-legal` GitHub repo.
4. Under repository Settings > Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Verify these URLs resolve publicly:
   - https://lbeteta.github.io/betetaai-legal/privacy.html
   - https://lbeteta.github.io/betetaai-legal/terms.html
6. Set up a real, independently verifiable opt-in process. A GitHub Pages legal website alone is **not** proof of consent.

These pages are starter legal disclosures and should be checked for applicability before business/customer production usage.
